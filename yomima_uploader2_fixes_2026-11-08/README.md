## 取り込んだあとに気をつけること

1. **起動前に、鍵を外から渡す必要があります**
   - `SECRET_KEY`（作者ログイン用）は必須です。渡さないと起動しません。
   - 例: `SECRET_KEY` には推測できない長い文字列を入れてください（`python3 -c 'import secrets; print(secrets.token_hex(32))'` で作れます）。
   - 管理者機能を使う場合は `ADMIN_PASSWORD` と `ADMIN_SECRET_KEY` も渡してください。`ADMIN_PASSWORD` だけ渡して鍵を忘れると、起動の時点で止まります。
   - 鍵を新しくすると、今までのログイン証明書は使えなくなります。再ログインが必要です。

2. **必要に応じて渡す設定があります**（使っている運用に合わせて）
   - `CORS_ALLOWED_ORIGINS`： プラットフォームを別の住所の画面から使う場合に、許可する住所を書きます。
   - `TRUST_CF_CONNECTING_IP`： Cloudflare を経由する運用で、Cloudflare が付ける住所（IP）を使いたい場合に `1` を入れます。
   - `MANGA_DOWNLOAD_ALLOWED_HOSTS`： 名前の解決が内部向けの宛先になる特殊な中継環境で、外部の作品を取り込む場合に許可する宛先を書きます。
   - プラットフォームの住所の設定（`PLATFORM_BASE_URL`）は、ビューワーから見た実際の住所とそろえてください。サムネイルの取り寄せ先はこの設定から作ります。

3. **テストの動かし方**
   - 必要な部品を入れた環境で、リポジトリの場所で `python -m pytest tests/ -q` を実行すると、115件のテストが動きます。
   - テスト用の鍵は `tests/conftest.py` が自動で渡すので、テストのときに本物の鍵は要りません。
